# Cognito

> Cognito (cognitohq.com, operated by BlockScore, Inc.; acquired by Plaid) is an identity verification, KYC, and AML compliance API. It turns a phone number, name, or ID document into a verified identity in under a minute across 209 countries. Three products share one REST API: Identity (phone-first verification), Flow (hosted/embeddable all-in-one verification with document + selfie checks), and Screening (watchlist / sanctions / PEP AML screening). The API is JSON:API (application/vnd.api+json), date-versioned via a Cognito-Version header, and authenticated with HTTP request signatures (HMAC-SHA256).
